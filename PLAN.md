# План разработки Android-приложения задач

## Цели и требования
- Минималистичное приложение задач, аналог Google Tasks.
- Android 10+.
- Локальное хранение задач.
- Импорт/экспорт бэкапа без облака.
- Виджет на главный экран с прокручиваемым списком.

## Функциональные требования (MVP)
- Список задач: создать, удалить, отметить выполненной.
- Закрепление задач: максимум 2 закреплённых задачи сверху списка.
- Импорт/экспорт бэкапа в **JSON**.
  - Импорт объединяет данные (merge).
  - При импорте помечаем задачи флагом `isImported`.
  - В UI рядом с импортированной задачей отображается метка **"i"** серым текстом.
  - Если импортируемая задача дублирует существующую по названию — **пропускать**.
- Виджет отображает **только невыполненные** задачи.
- Из виджета можно отметить задачу выполненной.
- Тёмная тема обязательна.

## Архитектура и стек
- Kotlin + Android Jetpack.
- Room (SQLite) для хранения задач.
- ViewModel + Flow/LiveData.
- kotlinx.serialization для JSON импорта/экспорта.
- AppWidgetProvider + RemoteViewsService для виджета-списка.

## Модель данных (черновик)
```
Task
- id: Long
- title: String
- isDone: Boolean
- isPinned: Boolean (max 2)
- isImported: Boolean
- createdAt: Long
```

## Экспорт/импорт (JSON)
- Экспорт: список задач в JSON файл через Storage Access Framework.
- Импорт: читаем JSON и объединяем с текущей базой.
  - Пропускаем задачи, если `title` совпадает с существующей.
  - Новые задачи помечаем `isImported = true`.

## Виджет
- Прокручиваемый список (`RemoteViewsService`).
- Показывает только невыполненные задачи.
- Клик по задаче → отметить как выполненную.
- Кнопка "+" или тап по заголовку → открыть приложение.

## Этапы реализации
1. **База и экран списка**
   - Room + DAO + Repository.
   - UI списка задач (Compose или XML, уточнить).
   - CRUD и отметка выполненной.
   - Закрепление (ограничение 2).
2. **Импорт/экспорт**
   - SAF для выбора файла.
   - JSON сериализация.
   - Merge-логика с `isImported`.
3. **Виджет**
   - RemoteViewsService.
   - Обработка клика на задаче.
   - Обновление виджета при изменениях базы.
4. **Тёмная тема**
   - Material theme (M3 или M2).
   - Проверка контрастности.

## Решения, зафиксированные заказчиком
- Формат бэкапа: JSON.
- Импорт: merge + пометка импортированных задач.
- Метка импортированных: серый текст "i".
- Дубликаты по названию: пропускать.
- Виджет: только невыполненные.
- Минимальная версия Android: 10.
- Тёмная тема обязательна.
